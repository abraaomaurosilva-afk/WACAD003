## Projetos

### 1. Gerador de Histórias de Séries
Exercício inspirado no **Silly Story Generator** da MDN, adaptado para o tema de séries.

### 2. Galeria Stranger Things
Galeria de imagens com miniaturas, imagem principal e recurso para escurecer/clarear a visualização.

### 3. Simulador de Partículas
Aplicação com **Canvas**, JavaScript e conceitos de orientação a objetos para simular partículas e formas geométricas.

## Como executar

1. Clone o repositório.
2. Abra a pasta da atividade desejada no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server**.

```bash
git clone https://github.com/abraaomaurosilva-afk/WACAD003.git
cd WACAD003
```

Cada atividade fica em sua própria pasta. Arquivos duplicados e versões antigas não ficam na raiz do repositório, deixando o projeto mais simples para avaliação e manutenção.
